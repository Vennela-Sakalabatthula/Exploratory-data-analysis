# Task 3: Exploratory Data Analysis (EDA)

## Objective
To perform Exploratory Data Analysis (EDA) on the Student Performance Dataset and identify patterns, trends, and relationships using statistical summaries and visualizations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Student Performance Dataset (Portuguese Language)

## Visualizations Performed
- Histogram
- Correlation Heatmap
- Boxplot
- Study Time vs Final Grade Scatter Plot

## Key Findings
- Strong correlation between G1, G2, and G3 grades.
- Study time positively impacts student performance.
- Presence of a few outliers in grade distributions.
- Useful patterns identified through visual analysis.

Learned how to explore datasets, generate summary statistics, visualize data, and identify meaningful patterns using EDA techniques.
